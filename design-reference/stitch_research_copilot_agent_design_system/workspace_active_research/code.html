Standard scaled dot-product attention computes all pairwise token interactions simultaneously, which minimizes sequential path length to O(1) but materializes an N × N attention matrix in GPU high-bandwidth memory (HBM) [Vaswani et al., p. 4].

Attention(Q, K, V) = softmax( (Q · KT) / √dk ) · V
Eq. (1)

FlashAttention-2 avoids materializing the full N × N matrix by tiling Q, K, V blocks into on-chip SRAM and applying online softmax rescaling, reducing HBM reads and writes from quadratic to linear in sequence length [Dao, p. 3–5].
